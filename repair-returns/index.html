匯入與備份

從舊系統移入 Word

可一次選多個 .doc 或 .docx。匯入前可核對每份檔案的品項、照片和金額。舊版 Word 沒有記載的歸還狀態會標成「待確認」。

完整備份

這台裝置會自動儲存草稿。「匯出完整備份」可保留草稿、歷史紀錄、照片、歸還狀態與日期。換機或移除 App 前，請將備份存入「檔案」或 iCloud Drive。

移轉舊系統的歸還日期與歷史時間

若還能編輯舊系統的原始專案，可在原本的裝置與帳號執行唯讀匯出元件。請先保留原始 App.tsx，等草稿儲存完成，再暫時以此元件開啟同一個專案。核對筆數並下載 JSON 後，可恢復原程式。
